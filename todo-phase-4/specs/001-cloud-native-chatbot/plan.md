# Implementation Plan: Cloud-Native AI Chatbot Migration

**Branch**: `001-cloud-native-chatbot` | **Date**: 2026-02-02 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/001-cloud-native-chatbot/spec.md`

## Summary

Migrate the Phase 3 AI Chatbot (Next.js frontend + FastAPI backend) to a Cloud-Native architecture running on Minikube. This plan defines four distinct implementation phases: Workspace Setup (completed), AI-Assisted Containerization using Gordon, Kubernetes Orchestration using kubectl-ai/Kagent for Helm chart generation, and Local Deployment with verification. All implementation tasks are designed for AI agent execution—no manual coding.

## Technical Context

**Language/Version**: Python 3.10+ (backend), Node.js 18+ (frontend)
**Primary Dependencies**: FastAPI, uvicorn, SQLModel, LiteLLM (backend); Next.js 16.1.4, React 19, Tailwind CSS v4 (frontend)
**Storage**: PostgreSQL (external, shared with Phase 2)
**Testing**: pytest, pytest-asyncio (backend); no test suite specified (frontend)
**Target Platform**: Minikube (local Kubernetes cluster) on Windows
**Project Type**: Web application (frontend + backend)
**Performance Goals**: Pod startup < 2 minutes, chat response < 5 seconds
**Constraints**: Combined image size < 500MB, stateless services, external database
**Scale/Scope**: Single-node Minikube, configurable replica counts (default: 1)

```text

- Image: chatbot-frontend:local

- Environment variable: NEXT_PUBLIC_API_URL (from ConfigMap)
- Liveness probe: HTTP GET / port 3000
- Readiness probe: HTTP GET / port 3000
- Service type: ClusterIP

Service 2: chatbot-backend
- Image: chatbot-backend:local
- Port: 8001
- Replicas: 1 (configurable)
- Resources: requests 256Mi/200m, limits 512Mi/500m
- Environment variables from Secrets: GEMINI_API_KEY, DATABASE_URL
- Environment variables from ConfigMap: LLM_MODEL
- Liveness probe: HTTP GET /health port 8001
- Readiness probe: HTTP GET /health port 8001
- Service type: ClusterIP

Additional resources:
- ConfigMap: chatbot-config (API URLs, model settings)
- Secret: chatbot-secrets (API keys, database URL)
```
